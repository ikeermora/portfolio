Context

Simple Silicon is a desktop EDA environment for SystemVerilog design. It brings RTL editing, simulation, waveform inspection, and hardware visualization into one workspace.

I design the product architecture, interface, and verification workflows alongside my own digital hardware projects.

The problem

Writing RTL is only part of understanding a digital system. The source, the structure it describes, and its behavior over time need to be readable together.

The aim is a clearer path between those views, with tools that make hardware development more accessible.

What I built

A desktop environment for editing SystemVerilog, running simulations, and inspecting waveforms. An interactive RTL Visualizer exposes module hierarchy, internal logic, gates, multiplexers, signals, and connections.

Write RTL→Simulate→Inspect

Technical approach

The application uses TypeScript and React for the interface, with Rust and Tauri for the desktop environment. Yosys elaborates the RTL for the hardware visualizer.

Silicio-16 provides a practical verification workload: arithmetic, memory operations, control flow, and complete programs that can be examined through simulation traces.

Current state

In active development. The existing Silicio-16 verification captures demonstrate waveform inspection across individual instructions and full-program execution.

The product remains focused on a simple goal: making digital hardware easier to build and understand.
